# iOS Next 1.0.9 — What’s New

- New unified Control Center combining Runner and Owner Control behind the existing Owner login, token, Face ID and device binding.
- Owner access removed from Chat and moved to System → Control Center.
- Runner dashboard expanded with tappable details for registered, free and busy runners plus CPU, RAM and storage.
- Runner/job contracts prepared for runner names, labels, repositories, branches, workflows and active jobs.
- Commander Live lifecycle fixed so opening detail views no longer drops LIVE to OFFLINE.
- Normal navigation cancellation no longer appears as “Runner-Aktion fehlgeschlagen — cancelled”.
- Owner projects, workflows, logs, diagnostics, backups, systems, security, communication, releases and tickets integrated into Control Center.
- Owner Health Check works safely in observe mode; CI metadata support and protected GitHub token configuration prepared.
- Light Master fixed to control Home Assistant groups through the correct homeassistant service domain.
- Media Master now shows “Alle Medien anschalten” when everything is off and hides irrelevant volume/playback controls while the media zone is off.
- Focus-ready moon accent updated to the matching indigo Focus/Do Not Disturb color.
- New polished startup reveal and Control Center unlock animation driven by a deterministic 120 Hz motion timeline with Reduce Motion support.
- New semantic sound and haptic feedback system for navigation, device-state changes, errors and secure Control Center unlocks.
- Repository mapping corrected for the current iOS-App repository and release/readiness checks expanded.
