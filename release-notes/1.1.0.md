# iOS Next 1.1.0

- Motion V2 ist vollständig auf die kanonische Dark-Mode-Baseline mit 223 Frames umgestellt.
- Die App erzwingt Dark Mode zur Laufzeit.
- Fire-TV-Companion erhält capability-gesteuerte D-Pad-Navigation mit Hoch, Runter, Links, Rechts und OK sowie Back, Home, Menü und Recents, soweit unterstützt.
- Home-Assistant-Raumzuordnung nutzt eine zentrale Entity-zu-Device-zu-Area-Normalisierung; Geräte werden über device_id dedupliziert.
- Ungültige Zustände wie unavailable, unknown, none und leere Werte werden ohne irreführende Einheiten dargestellt.
- Commander/MCP zeigt ausschließlich sanitisierten read-only Arbeitskontext für Repository, Branch, Workflow, Job, Phase, Step, Runner, letzte/nächste Aktivität und Laufzeit; keine erfundenen Prozentwerte.
- Der finale Release-Gate verwendet die bereits akzeptierte Dark-Mode-Motion-Baseline; für diesen Release wurde kein Motion-Capture erneut ausgeführt.
